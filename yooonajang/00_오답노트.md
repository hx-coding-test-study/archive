# 오답노트 (복습용)

> 내일 이 파일 하나만 훑으면 됨. 위 요약만 봐도 되고, 기억 안 나는 항목만 아래 문제별 상세 + 치트시트 링크로 확인.

---

## 핵심 요약 (이것만 봐도 감 잡힘)

1. **참조(`&`) vs 복사** — `for (vector<int>& v : board)`에 `&` 없으면 `v[i]=0` 해도 원본 안 바뀜. 파이썬은 기본이 참조(자동), C++는 기본이 복사(명시적 `&` 필요).
2. **`cout <<`, `cin >>`** — 방향 반대로 쓰면 컴파일 에러. 출력은 `<<`.
3. **`pair<int,int> p = {3,5};`** — `<>`엔 항상 타입만, 값은 `{}`. `vector<int,int>`는 문법 자체가 틀림 (→ `pair` 써야 함).
4. **`find` / `max_element`는 값이 아니라 위치(iterator)를 반환** — `*`로 값 꺼내고, `-begin()`으로 인덱스 변환. 그리고 **둘 다 "제일 처음 것" 하나만 찾음** — 여러 개(공동 1등 등) 찾으려면 직접 for문으로.
5. **`next_permutation`**: 꼭 `sort` 먼저 + `do { } while(next_permutation(...))`로 감싸기. `#include <algorithm>`. 값 같은 원소는 자동으로 중복 순열 건너뜀.
6. **`%`로 패턴 순환**: `pattern[i % pattern.size()]` — 짧은 패턴 계속 반복시킬 때.
7. **`stack`**: `top()`/`push()`/`pop()`, LIFO. "방금 넣은 것 vs 그 아래 것" 비교 패턴 (크레인류).
8. **`queue`**: `front()`/`push()`/`pop()`, FIFO. BFS는 꼭 `vector` 대신 `queue` (앞에서 빼는 게 O(1) vs O(n)).
9. **헤더 기억 안 나면** `#include <bits/stdc++.h>` 하나로 다 해결 (프로그래머스는 대부분 허용).
10. **`core dumped`/런타임 에러 디버깅 순서**: ① 인덱스 범위 초과(특히 숫자 하드코딩) ② 빈 stack/queue에서 top/pop ③ 2차원 배열 행/열 순서 ④ 재귀 무한루프 ⑤ 0으로 나누기. `vector`의 `[]`는 범위 벗어나도 에러 안 내고 조용히 메모리를 깨뜨림 — 그래서 터짐.

## 자잘한 것 모음

- `count`: vector에 쓰면 "개수", map/set에 쓰면 "있는지(0/1)" — 같은 이름 다른 의미
- `erase(v.begin()+i)`: 인덱스 아니고 iterator 위치로 지정
- `arr[-1]` C++엔 없음 → `v.back()`. 슬라이싱도 없음 → `vector<int> sub(begin+a, begin+b)`로 흉내
