# 하이닉스 코딩 테스트 스터디

SK하이닉스 코딩 테스트 대비 스터디입니다. **1일 1문제**, 프로그래머스 문제로 30일 커리큘럼을 진행합니다.

## 진행 방식

- 하루에 한 문제씩 풉니다. 아래 커리큘럼 순서를 따릅니다.
- 푼 코드는 이 레포에 올립니다. 파일 이름은 `문제번호_문제이름.확장자` 형식을 권장합니다. (예: `42840_모의고사.cpp`)
- **레포 최상위에 파일을 올리면 자동으로 본인 GitHub ID 폴더로 이동됩니다.** 폴더가 없으면 자동으로 생깁니다. 처음부터 본인 폴더 안에 올려도 됩니다.

## SK하이닉스 코딩 테스트 정보 (인터넷 후기 기반)

실제 응시 후기들을 종합한 내용입니다.

| 항목 | 내용 |
|------|------|
| 환경 | 프로그래머스 |
| 언어 | C / C++ |
| 문제 수 / 시간 | 3~4문제 / 약 90분 |
| 출제 유형 | **완전탐색, 시뮬레이션, 구현** 위주. 자료구조 기본기도 필요 |
| 형식 | 정답을 return하는 함수 작성 (solution 함수 형식, 파라미터 변경 불가) |
| 기타 | 주석·코딩 스타일도 채점 요소라는 후기가 있음 |

체감 난이도는 프로그래머스 Lv1 상위 ~ Lv2 수준이라는 후기가 많습니다. 그래서 커리큘럼도 Lv1으로 시작해 Lv2 완전탐색·시뮬레이션에 비중을 두었습니다.
